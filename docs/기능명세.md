# 기능 명세 · 진행 체크리스트

Claude Code · Gemini CLI · Codex CLI 를 벤치마킹한 기능 목록.
각 항목은 **구현 완료 시 `[~]`, 구현 + 테스트 통과 시 `[x]`** 로 표시한다.
(테스트: 자동 테스트 또는 `docs/이슈목록.md` 의 해당 이슈에 검증 절차 기록)

범례 - 벤치마크 열: ✅ 지원 / 🟡 부분·유사 / ➖ 없음

## A. 에이전트 코어

| 기능 | CC | Gem | Cdx |
|---|:--:|:--:|:--:|
| 에이전트 루프 (툴 호출 → 실행 → 관찰 반복) | ✅ | ✅ | ✅ |
| 스텝/토큰 예산 및 중단 조건 | ✅ | ✅ | ✅ |
| 계획(plan) 모드 - 편집 없이 계획만 제시 | ✅ | 🟡 | 🟡 |
| 확장 사고(thinking) 토글 | ✅ | 🟡 | ✅ |
| 작업 목록(todo) 추적 및 표시 | ✅ | ➖ | 🟡 |
| 서브에이전트 - 하위 작업을 별도 컨텍스트로 위임 | ✅ | ➖ | 🟡 |

- [ ] **A1. 에이전트 루프** — 시스템 프롬프트 + 툴 정의 → 모델 응답 파싱 → 툴 실행 → 결과 주입 반복
- [ ] **A2. 예산·중단 제어** — 최대 스텝/토큰, 반복 감지, 사용자 취소(Ctrl-C) 안전 처리
- [ ] **A3. 계획 모드** — `giga plan` 또는 `--plan`: 파일 변경 없이 단계 계획만 출력, 승인 후 실행
- [ ] **A4. 사고 모드** — `--think` / `--think-hard`: reasoning 계열 모델 사용 또는 사고 토큰 확대
- [ ] **A5. 작업 목록 추적** — 다단계 작업을 체크리스트로 분해·표시·갱신
- [ ] **A6. 서브에이전트** — `orchestra/` 와 연계해 하위 작업을 독립 컨텍스트/모델로 위임
