- [ ] 로컬 모델(Ollama)에 연결해 실제 리포에서 "버그 고쳐줘" 수행
- [ ] `giga doctor` 로 장비별 모델 추천 + `giga model use` 로 선택
- [ ] repo map 자동 주입, 컨텍스트 초과 없이 대형 리포 대응
- [ ] AGENTS.md + 장기 메모리 로드/기록
