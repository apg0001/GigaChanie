## 남은 것

기능명세(`기능명세.md`)의 항목은 F4(셸 샌드박스)를 빼고 전부 `[x]`(구현+테스트).
F4 는 Linux/macOS 에서 동작하고 Windows 미지원·도커는 선택이라 `[~]` 로 남겨 둔다.
아래는 코드 기능이 아니라 환경·배포·다듬기.

- **F4 도커 샌드박스** — 셸 격리는 bwrap/firejail/seatbelt 로 동작. 도커는 대안 백엔드(선택).
- **배포** — PyPI 출시(`giga self update` 가 전제), VS Code Marketplace 등록(vsce 퍼블리셔 계정).
- **실모델 셰이크아웃** — 대부분의 테스트가 ScriptedBackend. 실제 로컬 모델로 더 돌려보며 다듬기.

## 스택

- CLI: Python 3.11+, typer + rich, psutil, pyyaml, httpx, prompt-toolkit, platformdirs
- 서빙: Ollama(`/api/chat`) / OpenAI 호환(llama.cpp·MLX·vLLM·호스팅). 툴콜은 네이티브 + 본문 JSON 복구
- 확장: TypeScript, `giga serve` stdio JSON-RPC 를 자식 프로세스로
- 선택 의존: `[pdf]` pypdf · `[docs]` python-pptx/docx/markdown · `[otel]` opentelemetry-sdk
